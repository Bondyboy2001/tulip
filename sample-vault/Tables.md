# Tables

Put the cursor anywhere outside a table and it renders. Click any cell, or move
the caret into it, and the pipes come back so you can edit the markdown directly.

| Infinitive | Main clause | Meaning |
|---|:---:|---:|
| opstaan | ik **sta** op | to get up |
| meegaan | ik ga mee | to `come` along |
| aankomen | ik kom aan | to arrive |

Alignment comes from the delimiter row: `:---:` centres, `---:` right-aligns.
